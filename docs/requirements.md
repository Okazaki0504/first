# 要件メモ（v0.1 / 2026-11-27）

| 項目 | 決定内容 |
|---|---|
| 中心機能 | 学習時間の記録・可視化 / 学習計画・進捗管理 / 過去問の正誤記録 / 同梱一問一答（1次・2次の基礎練習） |
