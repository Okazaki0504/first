# 要件メモ（v0.1 / 2026-11-27）

| 項目 | 決定内容 |
|---|---|
| 中心機能 | 学習時間の記録・可視化 / 学習計画・進捗管理 / 過去問の正誤記録 / 同梱一問一答（1次・2次の基礎練習） |
| 対象 | 1次7科目 + 2次4事例 |
| 販売形態 | 買い切り有料（価格未定） |
| データ保存 | 端末内のみ |
| 一問一答 | Claudeがオリジナル問題作成 → オーナーが検証。各科目約100問 |
| デザイン | RPGゲーム風（レベル・EXP・連続日数・デイリークエスト・モンスター討伐） |
| 技術 | Flutter + Codemagic + TestFlight |

モック: mock/index.html（https://claude.ai/artifact/1rZy4CuqbJxBEyKjJincjo）

## v0.2 追加決定（2026-11-27）
| 項目 | 決定内容 |
|---|---|
| 主人公 | レベルと称号のみ（職業・装備の選択なし） |
| GOLD | 消費しないスコア。累計GOLDで拠点が 村(0)→街(1,000)→城(3,000) と成長（しきい値は仮） |
| タイマー | 自由計測＋ポモドーロ(25/5)＋手入力 |
| 通知 | 毎日、ユーザーが設定した時刻にローカル通知 |
| 2次対策 | 一問一答のみ（記述の自己採点・計算ドリルはなし） |
| 価格 | 980円を第一候補（1,000円も可） |
| 出題形式 | 4択＋○×の混合 |

## v0.3 追加決定（2026-11-27）
| 項目 | 決定内容 |
|---|---|
| 復習 | 忘却曲線で自動出題「復習の塔」（1→3→7→14日後、3回連続正解で卒業） |
| 演出 | 振動のみ（効果音・BGMなし）。設定でオフ可 |
| アプリ名 | 中小企業診断士 学習アプリ（副題：学習管理×一問一答）※App Storeで名前が使用済みなら代案を検討 |
| 初回起動 | 短い物語（3画面）＋設定3問（受験区分・試験日・週の目標時間） |

## v0.4 追加決定（2026-11-27）
