0. 全体像

①準備アカウント4つ作成
②要件決めモックを見て質問に回答
③開発Claude Codeがコードを書きGitHubへ
④ビルドCodemagicのMacで自動ビルド
⑤テストTestFlightで自分のiPhoneへ
⑥販売App Store審査→公開

なぜMacなしでできるのか

iPhoneアプリのビルドには本来Mac（Xcode）が必要です。この手順ではCodemagicというクラウド上のMacにビルドと署名を任せます。コードはClaude Codeがクラウド上で書き、GitHubに保存。GitHubに保存されるとCodemagicが自動でビルドし、TestFlight（Appleのテスト配信アプリ）経由であなたのiPhoneに届きます。

開発技術：Flutterを採用

「お任せ」の回答を受け、Flutterを採用します。理由は3つです。(1) Codemagicの標準対応で設定が簡単。(2) Claude Code側でWeb版として動作確認でき、ビルド失敗の往復を減らせる。(3) RPG風のアニメーションや独自デザインを作りやすい。

1. 準備：アカウントを作る

②の要件決めと並行して進めてください。特にApple Developerは審査に時間がかかることがあるので最初に申し込みます。

1-1. Apple ID の2ファクタ認証を確認 あなた

  1. iPhoneの 設定 → 一番上の 自分の名前 → サインインとセキュリティ を開く。
  2. 2ファクタ認証 が「オン」になっていることを確認。オフなら画面の指示でオンにする。

1-2. Apple Developer Program に登録 あなた

  1. App Storeで「Apple Developer」アプリ（Apple公式・無料）をインストール。
  2. アプリを開き、下部の アカウント → Apple IDでサインイン。
  3. 今すぐ登録（Enroll Now）をタップ。
  4. 登録区分は 個人 を選ぶ（法人で売る場合はD-U-N-S番号が必要になり時間がかかる）。
  5. 氏名・住所はローマ字で入力（例：Taro Yamada）。App Storeの販売者名として本名が表示されます。
  6. 本人確認書類の撮影を求められたら画面の指示どおり撮影する。
  7. 年会費を支払う（App内課金として処理される）。
  8. 「登録完了」のメールが届くまで待つ（数分〜数日）。
ここで販売の準備も済ませる登録完了後、Safariで appstoreconnect.apple.com を開き、ビジネス（または「契約／税金／口座情報」）から有料Appの契約に同意し、銀行口座と税務情報（日本居住の個人は米国税務フォーム W-8BEN）を登録します。これがないと有料販売できません。続けて Small Business Program（手数料15%）にも申請します（Safariで developer.apple.com/app-store/small-business-program/）。

1-3. GitHub アカウントとリポジトリ あなた

このリポジトリ okazaki0504/first は既にあり、Claude Codeと接続済みです。新しく作り直す必要はありません。

  1. App Storeで「GitHub」公式アプリをインストールしてサインイン（進捗やビルド結果の確認用）。
  2. リポジトリを非公開にしたい場合：Safariで github.com/okazaki0504/first → Settings → 一番下の Change visibility → Make private。
    ※有料アプリのソースなので非公開を推奨。

1-4. Codemagic アカウント あなた

  1. Safariで codemagic.io を開き Sign up → Sign up with GitHub。
  2. GitHubの許可画面で Authorize。アクセスできるリポジトリに first を含める。
  3. チーム作成を聞かれたら個人（Personal account）を選ぶ。
Safariで操作しにくいときCodemagic・App Store ConnectはPC向け画面です。Safariのアドレスバー左の ぁあ → デスクトップ用Webサイトを表示 にすると操作しやすくなります。

2. 要件を固める（モック＋質問の往復）

Claude Codeのリソースを節約するため、本物のアプリを作る前にブラウザで触れるモックで画面と遊び方を固めます。

  1. あなた モックのURLをiPhoneのSafariで開き、全5タブ（拠点・バトル・修行・記録・冒険の書）を触る。
  2. あなた 気になった点をClaude Codeのチャットに箇条書きで送る。例：「バトルの効果音が欲しい」「拠点にキャラ育成を」「タイマーは25分ポモドーロ固定で」。
  3. Claude 質問を返しながらモックを更新（URLは同じまま）。
  4. 2〜3を「このまま作ってOK」と言えるまで繰り返す。最終版の要件はClaudeが docs/requirements.md に書き出します。

3. 開発：Claude Codeに作ってもらう

3-1. iPhoneからClaude Codeを使う あなた

  1. Claudeアプリ（またはSafariで claude.ai/code）を開き、このセッションを開く。
  2. 要件が固まったら次のように依頼する：
    モックの最終版と docs/requirements.md に沿って、Flutterで本番アプリを実装してください。Codemagic用の codemagic.yaml も作成し、ブランチにpushしてください。
  3. Claudeが作業し、GitHubにコードをpush（保存）します。完了報告を待つ。

3-2. Claudeが行うこと Claude

  • Flutterプロジェクト作成（画面・RPG演出・データ保存・一問一答データ）
  • 一問一答をデータファイル（assets/questions/*.json）として作成 → 検証用の一覧PDFも出力
  • 自動テストを書き、Web版で動作確認
  • codemagic.yaml（ビルド・署名・TestFlight送信の設定）を作成
  • プライバシーポリシー（「データを収集しません」）のページを作成

3-3. 問題の検証 あなた

  1. Claudeが出力する「問題検証シート（PDF）」を科目ごとに確認する。
  2. 誤り・あいまいな選択肢を見つけたら、問題IDと修正内容をチャットで送る（例：「fin-023 の正解はBでは？」）。
  3. Claudeが修正し、根拠も併記して再出力。全科目で「OK」が出るまで繰り返す。
著作権の注意過去問の問題文・選択肢をそのまま収録すると著作権侵害のおそれがあります。アプリにはオリジナル問題のみを収録し、過去問は「年度・問題番号ごとの○×記録」だけに使います。市販テキストの文章を写して送るのも避けてください。

4. ビルド：Codemagicの設定（最初の1回だけ）

4-1. Bundle ID（アプリの識別子）を登録 あなた

  1. Safari（デスクトップ表示）で developer.apple.com/account → Certificates, IDs & Profiles → Identifiers → ＋。
  2. App IDs → Continue → App → Continue。
  3. Description：Shindan Quest、Bundle ID：Explicit を選び、com.okazaki0504.shindanquest を入力 → Continue → Register。

4-2. App Store Connect にアプリを登録 あなた

  1. Safariで appstoreconnect.apple.com → アプリ → ＋ → 新規App。
  2. プラットフォーム：iOS／名前：App Storeに表示する名前（他と重複不可）／言語：日本語／バンドルID：4-1で登録したもの／SKU：shindanquest001（任意の英数字）／アクセス：フルアクセス → 作成。

4-3. App Store Connect API キーを作る あなた

CodemagicがあなたのかわりにAppleへ署名・アップロードするための「合鍵」です。

  1. App Store Connect → ユーザとアクセス → 統合（Integrations）タブ → App Store Connect API。
  2. 初回はアクセスをリクエスト／同意する。チームキー の ＋（キーを生成）。
  3. 名前：Codemagic、アクセス：App Manager → 生成。
  4. 画面に出る Issuer ID と キーID をメモアプリに控える。
  5. APIキーをダウンロード で .p8 ファイルを保存（iPhoneの「ファイル」アプリに保存される）。ダウンロードは1回きりなので、iCloud Driveなど安全な場所に保管。
秘密情報の扱い.p8ファイル・Issuer ID・キーIDはClaudeのチャットに貼らないでください。Codemagicの画面にだけ入力します。

4-4. Codemagic にキーを登録 あなた

  1. Codemagic → チーム（または個人アカウント）の設定 → Team integrations（個人は Integrations）→ Developer Portal → Manage keys。
  2. Add key → App Store Connect API key name に codemagic_asc と入力（codemagic.yaml の名前と完全に同じにする）。
  3. Issuer ID・Key ID を入力し、Choose a .p8 file で4-3の.p8ファイルを選ぶ → Save。

4-5. 署名用の証明書をCodemagicで作る あなた

  1. Codemagic の設定 → codemagic.yaml settings → Code signing identities → iOS certificates タブ。
  2. 証明書をまだ持っていないので、Codemagicに新規作成させるボタン（Generate certificate／Create certificate など）を選ぶ。APIキーは codemagic_asc、種類は Apple Distribution、Reference name は dist_cert。
  3. 作成されると一覧に表示される（Appleの開発者サイトにも自動で登録されます）。

4-6. プロビジョニングプロファイルを作る あなた

  1. Safari（デスクトップ表示）で developer.apple.com/account → Certificates, IDs & Profiles → Profiles → ＋。
  2. Distribution の App Store Connect → Continue。
  3. App ID：4-1で登録した com.okazaki0504.shindanquest → Continue。
  4. 証明書：4-5でCodemagicが作ったもの（日付が今日のApple Distribution）を選ぶ → Continue。
  5. Provisioning Profile Name：ShindanQuest AppStore → Generate。
  6. Codemagic に戻り、Code signing identities → iOS provisioning profiles タブ → Fetch profiles → いま作ったプロファイルにチェック → Reference name を appstore_profile にして取り込む。Certificate 欄に緑のチェックが出ればOK。

4-7. リポジトリを追加してビルド あなた

  1. Codemagic → Apps → Add application → GitHub → okazaki0504/first を選ぶ → プロジェクト種別は Flutter App。
  2. 設定方法を聞かれたら codemagic.yaml を選ぶ（Claudeが作成済みの設定を使う）。
  3. Start new build → ブランチ claude/shindan-learning-app-r76up9 → ワークフロー ios-testflight → Start new build。
  4. 10〜20分待つ。緑のチェックで成功。成功するとTestFlightへ自動で送られます。
  5. 失敗したら：ビルド画面の赤い行をタップ → ログ全文をコピー（または画面のスクリーンショット）→ Claudeのチャットに貼って「直して」と送る。Claudeが修正をpushしたら再度 Start new build。

5. テスト：自分のiPhoneで動かす（TestFlight）

  1. あなた App Storeで「TestFlight」（Apple公式）をインストール。
  2. App Store Connect → 対象アプリ → TestFlight タブ。ビルドが「処理中」→「テスト可能」になるまで待つ（10〜30分）。
  3. 「輸出コンプライアンス」の質問は、アプリの設定で自動回答済み（暗号化なし）なので通常は表示されません。表示された場合は なし（標準の暗号化のみ）を選ぶ。
  4. 内部テスト の ＋ でグループを作り、自分（Apple ID）を追加。
  5. 届いた招待メール、またはTestFlightアプリを開き インストール。ホーム画面からアプリを起動。
  6. 使ってみて不具合や改善点をClaudeに送る → 修正 → Codemagicで再ビルド → TestFlightで自動更新、を繰り返す。
効率化Claudeが codemagic.yaml に「ブランチにpushされたら自動ビルド」を設定すると、4-7の手動ビルドが不要になります。ただし無料枠の分数を消費するので、修正をまとめてからpushするよう依頼すると節約できます。

テストのチェックリスト

  • 初回起動〜試験日設定がわかりやすいか
  • タイマーを動かしたまま画面ロック・他アプリに切り替えても時間が正しいか
  • アプリを削除せずに更新しても、記録が消えないか
  • 一問一答を連続で解いて、レベルアップ・クエスト達成の演出が正しく出るか
  • 文字サイズを最大（設定→画面表示と明るさ→テキストサイズ）にしても崩れないか
  • 機内モードでもすべての機能が動くか

6. 販売：App Store に申請する

6-0. プライバシーポリシーとサポートページを公開する あなた

審査には、誰でも開けるURLが必要です。アプリ本体のリポジトリは非公開のまま、ページだけを別の公開リポジトリで無料公開します。

  1. 問い合わせ専用のメールアドレスを作る（例：Gmailで新規作成）。
  2. Safariで github.com/new を開く。Repository name に shindan-support、Public を選び、Add a README file にチェック → Create repository。
  3. Claudeに「shindan-support を作った。連絡先は ○○@gmail.com」と送る。Claude がページ（docs/site/ の内容）をそのリポジトリに送ります。
  4. リポジトリの Settings → Pages → Branch を main・フォルダを / (root) にして Save。
  5. 数分後、https://okazaki0504.github.io/shindan-support/privacy.html がSafariで開ければ完了。このURLをApp Store Connectの「プライバシーポリシーURL」、…/support.html を「サポートURL」に入力します。

6-1. Claudeに用意してもらうもの Claude

  • App Store用スクリーンショット5枚（作成済み：docs/screenshots/、6.9インチ 1320×2868）
  • アプリ説明文・キーワード・サブタイトル・審査メモ（作成済み：docs/appstore_listing.md）
  • プライバシーポリシーとサポートページ（作成済み：docs/site/）
  • アプリアイコン（作成済み・アプリに組み込み済み）

6-2. App Store Connect で入力 あなた

  1. 対象アプリ → App情報：カテゴリ（例：教育）、コンテンツ配信権（第三者コンテンツなし）を設定。
  2. 価格および配信状況：価格を選ぶ（例：¥600〜¥1,200帯から選択）、配信国（まずは日本のみ推奨）。
  3. Appのプライバシー：データを収集しない を選び公開。プライバシーポリシーURLを入力。
  4. 左の「iOS App 1.0」→ スクリーンショットをアップロード、説明文・キーワード・サポートURLを貼り付け。
  5. ビルド 欄の ＋ でTestFlightでテストしたビルドを選ぶ。
  6. 年齢制限：質問にすべて「なし」で回答（4+の見込み）。
  7. 審査メモ：「ログイン不要。全機能オフラインで利用可能」と記載。
  8. 審査用に追加 → 審査へ提出。
  9. 通常1〜2日で結果メール。「リジェクト」の場合は理由文をClaudeに貼れば対応案と修正を出します。
  10. 「配信準備完了」になればApp Storeで販売開始。
審査で注意される可能性がある点 ・「中小企業診断協会の公式アプリ」と誤解させる名称・説明はNG（「非公式」「独自問題」と明記）。
・「必ず合格」など根拠のない表現はNG。
・EUで配信する場合は「取引業者（Trader）」情報の公開が必要。最初は日本のみの配信が無難。

7. リリース後の運用

  • 問題の追加・修正：Claudeにデータ更新を依頼 → Codemagicでビルド → App Store Connectで新バージョン（1.0.1など）を作成して提出。
  • 試験日の更新：毎年の試験日程の公表後に初期値を更新（ユーザーが自分で変更もできる設計）。
  • レビューへの対応：App Store Connectの 評価とレビュー から返信できます。
  • 年会費：Apple Developer Programは毎年更新。更新しないとアプリが販売停止になります。

8. 次にあなたがやること

  1. 1-2 Apple Developer Program の登録を始める（審査待ちの間に要件を詰めます）。
  2. モックをiPhoneで触り、Claudeからの次の質問に答える。
  3. 1-4 Codemagicに GitHubでサインアップしておく。
